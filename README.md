# Module-End-Assignment-3_Python-Fundamentals---Survey-Feedback-Analyzer
Survey Feedback Analyzer

This project is a simple Python application that helps analyze customer feedback collected through surveys. It stores feedback data in a dictionary of lists, allows users to add new feedback entries, cleans textual data, and generates useful insights such as average ratings, word frequency counts, longest feedback comments, and unique words used across all feedbacks. The project demonstrates core Python concepts including functions, loops, dictionaries and data processing.
